
# Online Auction and Bidding System

## Project Overview
A Java console application that allows users to create auctions, view items, place bids, and determine auction winners.

## Objectives
- Understand object-oriented programming in Java.
- Manage auction items and bids.
- Validate bids and prevent invalid operations.
- Practice Git and GitHub for source code management.

## Technologies
- Java
- Git
- GitHub
- Java Collections Framework

## Features
- Create auction items
- View available auctions
- Place bids
- Close auctions and display winners

## How to Run
Compile the Java source files and run the Main class.

## Project Type
B.Tech First-Year Java Project

## Storage
Auction information is stored in memory and resets when the application closes.
